개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 2일

1. 이 앱은 무엇인가요

"YouTube 자동 업로더"(이하 "앱")는 저장소 소유자 한 사람이 자신의 YouTube 채널에 영상을 올리기 위해 만든 개인용 도구입니다. 앱은 다른 사용자를 받지 않으며, 소유자 본인의 Google 계정으로만 사용됩니다.

2. 접근하는 정보

앱은 사용자가 허용한 Google 권한으로 다음 작업만 합니다.

  • YouTube (youtube.upload, youtube): 본인 채널에 영상 업로드, 썸네일 설정, 재생목록에 영상 추가
  • Google Drive (drive): 사용자가 지정한 폴더의 영상, 썸네일, 설정 파일과 스프레드시트를 읽고, 처리한 파일을 지정한 다른 폴더로 옮기며, 업로드 결과 기록 파일을 그 폴더에 저장

앱은 지정한 폴더 밖의 파일이나 다른 개인정보를 읽지 않습니다.

YouTube API 서비스 사용

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. YouTube API 서비스로 처리되는 정보에는 Google 개인정보처리방침이 적용됩니다.

앱은 사용자의 기기에 쿠키 등 정보를 저장하거나 읽지 않습니다.

3. 저장과 보관

  • 로그인 정보(OAuth 리프레시 토큰)는 소유자의 GitHub 저장소 암호화 비밀값(Secrets)에만 저장됩니다.
  • 영상 파일은 업로드하는 동안에만 GitHub Actions 실행 환경에 임시로 내려받고, 실행이 끝나면 그 환경과 함께 삭제됩니다.
  • 앱은 별도의 서버나 데이터베이스를 운영하지 않습니다.

4. 제공과 공유

앱은 Google 사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고나 AI 모델 학습에 사용하지 않습니다. 데이터는 위 2번에 적은 업로드 작업에만 사용합니다.

이 앱이 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

5. 권한 철회와 데이터 삭제

Google 보안 설정 → 서드 파티 액세스에서 언제든 이 앱의 권한을 삭제할 수 있습니다. 권한을 삭제하거나 GitHub 저장소의 비밀값을 지우면 앱이 보관하던 인증 정보도 더 이상 쓸 수 없게 됩니다. 삭제하면 앱은 더 이상 계정에 접근할 수 없습니다.

English summary

This app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies to information processed through YouTube API Services. The app does not store or access cookies or other information on your device.

This is a personal, single-user tool that uploads videos from the owner's designated Google Drive folders to the owner's own YouTube channel. It uses the YouTube scopes (youtube.upload, youtube) to upload videos, set thumbnails and add videos to playlists, and the Drive scope (drive) only to read, move and write files in the folders the owner designates. The OAuth refresh token is stored only in the owner's encrypted GitHub repository secrets. Video files are held temporarily in the GitHub Actions runner during upload and deleted with it. No user data is sold, shared with third parties, or used for advertising or AI training. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time via the Google security settings page. Contact: GitHub Issues.
