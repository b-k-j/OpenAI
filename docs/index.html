YouTube 자동 업로더

본인의 Google Drive 폴더에 올려 둔 영상을 본인 YouTube 채널에 자동으로 업로드하는 1인 전용 도구입니다. 다른 사람에게 서비스로 제공하지 않습니다.

이 앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 보며, YouTube API 서비스로 처리되는 정보에는 Google 개인정보처리방침이 적용됩니다. 이 앱이 데이터를 다루는 방법은 개인정보처리방침에 있습니다.

동작 방식

  1. 채널 주인이 Google 계정으로 로그인해 앱에 YouTube 업로드와 Google Drive 접근 권한을 허용합니다 (OAuth 2.0).
  2. iPad 사진 앱에서 영상을 지정한 Google Drive 폴더에 올리고, 같은 폴더의 스프레드시트에 제목·설명·태그·예약 공개 시간을 적습니다.
  3. GitHub Actions가 1시간마다 폴더를 확인해 새 영상을 YouTube Data API(videos.insert)로 업로드합니다. 썸네일(thumbnails.set)과 재생목록(playlistItems.insert)도 함께 설정합니다.
  4. 업로드가 끝나면 영상을 완료 폴더로 옮기고 YouTube 영상 주소를 기록합니다.

권한 철회

Google 보안 설정 → 서드 파티 액세스에서 언제든 이 앱의 권한을 삭제할 수 있습니다.
